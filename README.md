# SWI V3

## Structured Workflow Intelligence

SWI V3 is a controlled continuation of SWI V2.

V3 is not treated as a rewrite and does not automatically inherit
V2 claims, authorization, proof, seals, or production status.

## Core continuation rule

V2 history may be inherited as historical input.

V2 status is not automatically V3 status.

Every inherited capability must be independently identified,
validated, and recorded in V3.

## Status discipline

Named ≠ Implemented
Implemented ≠ Tested
Tested ≠ Proven
Proven ≠ Sealed
Sealed ≠ Authorized

## Authority discipline

DATA ≠ EVIDENCE
EVIDENCE ≠ ADMISSION
ADMISSION ≠ AUTHORIZATION
AUTHORIZATION ≠ ACTION

## Conversation tracking

V3 introduces conversation-header traceability.

Conversation tracking is an observation and continuity mechanism.

Conversation tracking ≠ authorization.

Timestamp ≠ truth.

Conversation continuity ≠ authority continuity.

Previous approval ≠ current authorization.

## Current production status

PRODUCTION_AUTHORIZED = NO

This repository does not claim production authorization merely
because code, tests, CI, signatures, or repository permissions exist.
